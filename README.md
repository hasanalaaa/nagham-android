# نغم لأندرويد

مشغّل أغاني وفيديو، ينزّل من يوتيوب وغيره **من جهازك نفسه** بضغطة وحدة، والملف يدخل للمكتبة مباشرة.

## التثبيت

1. افتح صفحة التحميل من الموبايل: **https://nagham-app.pages.dev** واضغط «حمّل التطبيق»، أو الرابط المباشر:
   **https://github.com/hasanalaaa/nagham-android/releases/latest/download/nagham.apk**
2. لما يخلص التنزيل اضغط على الملف ← «تثبيت». إذا طلب إذن «تثبيت تطبيقات من هذا المصدر» وافق مرة وحدة.
3. افتح «نغم». يحتاج متصفح Chrome على الجهاز.

للتنزيل: الصق الرابط في «نغم» واضغط «تنزيل»، أو من يوتيوب ← مشاركة ← «نغم».

الموقع: https://nagham.pages.dev
